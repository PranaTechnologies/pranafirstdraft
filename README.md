# Perception Labs

Perception Labs develops perception, state estimation, localization, and onboard autonomy systems for autonomous machines operating in complex real-world environments.

## Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **3D Visualization:** Three.js (`SpatialFieldCanvas`)
- **Animation:** Framer Motion
- **Typography:** Manrope & IBM Plex Mono (`next/font/google`)
- **Icons:** Lucide React

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Verification

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

## Deployment

Configured for standard Next.js hosting (such as Vercel).
